Scanner USB atau Bluetooth mode keyboard (HID) cukup dicolok, atau dipasangkan lewat Windows (Settings → Bluetooth & devices); tidak ada pairing di aplikasi. Di halaman Kasir hasil scan langsung menambah barang. Scanner mode serial/COM dihubungkan di bawah.

Printer struk

Printer Bluetooth: pasangkan dulu di Windows, ia akan muncul sebagai port COM. Mode langsung butuh Chrome/Edge. Printer USB biasa dengan driver Windows paling mudah lewat "Driver Windows"; USB langsung butuh driver WinUSB. Klik Simpan pengaturan untuk menyimpan pilihan.
